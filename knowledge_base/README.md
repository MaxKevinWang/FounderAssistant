# Local knowledge documents

Supply PDF, HTML or text documents in these local directories:

- `legal_form_selection/`
- `funding_preparation/`
- `market_validation/`

Directory names determine the retrieval domain. Add documents before running `build_rag_index`; this source distribution includes no document corpus or prebuilt index. Local corpus files are ignored by Git. See the [knowledge-base guide](../docs/knowledge_base/README.md).
